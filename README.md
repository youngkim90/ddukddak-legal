# Ddukddak legal pages

The root Korean policy URL is shared by the Android and iOS apps. The main branch is published through GitHub Pages.

This branch contains **pre-publication drafts**, including Korean/English privacy and support pages. Do not merge while review notices or unresolved publication requirements remain. The review banner is not a substitute for a complete policy, an effective date, required notice or publication approval.

Publication readiness and store-declaration coordination are tracked in the private planning repository's iOS launch plan. The account-deletion page also corrects its navigation: supported current app versions expose Delete account at the bottom of Settings, while Profile is for editing profile details. This was checked against the iOS feature source and the current local origin/main snapshot; it is not a new deletion test. Existing terms and other product pages are outside this change. Nothing on this branch is published to the live Pages site until a separately reviewed publication.
