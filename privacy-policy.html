개인정보처리방침

현행 시행일: 2026년 5월 20일 · 개정안 검토일: 2026년 10월 25일

검토용 개정안 — 아직 공개·시행되지 않았습니다. 시행일, 진단 정보의 실제 보관 기간 및 국외 이전 고지를 확정한 뒤 게시합니다. 기존 2026년 10월 26일 암호화 백업 공지의 날짜와 내용은 유지합니다. 이번 문서 작업은 Android 앱·서버의 수집 코드를 변경하지 않습니다. iOS Apple 로그인 처리 항목을 설명에 추가하며 결제 조건은 다루지 않습니다.

서비스 웹사이트: tales.ddukddak.net

문의 연락처·서비스 주소 안내 갱신일: 2026년 10월 10일.

개정 안내 (2026년 10월 19일 공지): 2026년 10월 26일부터 제3조(암호화 백업본 보관 기간)와 제5조(데이터 백업 보관 위탁) 내용이 추가로 시행됩니다.

뚝딱동화(이하 "서비스")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 이와 관련한 고충을 원활하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

플랫폼·버전·로그인 방법에 따라 처리하는 항목이 다릅니다. Apple 로그인 항목은 해당 iOS 기능을 선택한 경우에만 적용하며 Android에 Apple 로그인을 추가한다는 뜻이 아닙니다. 네트워크 요청 과정에서 접속 IP·시각 등 요청 정보가 인증·서버·콘텐츠 전송 사업자에게 전달될 수 있습니다.

제2조 (개인정보의 수집·이용 목적)

  1. 회원 관리: 회원 식별, 본인 확인, 가입 및 탈퇴 처리
  2. 서비스 제공: 동화 콘텐츠 제공, 읽기 진행률 저장 및 복원. Apple 권한 철회용 토큰은 계정 연결과 탈퇴 시 권한 철회 처리에 사용
  3. 서비스 개선: 서비스 이용 통계 분석 (비식별 처리), 오류·충돌 원인 파악과 안정성 개선. 진단 정보 전체가 익명이라는 의미는 아님
  4. 문의 대응: 이용자가 보낸 문의 확인·답변 및 문제 해결
  5. 서비스 알림 발송: 새 동화 등록 등 서비스 운영과 관련된 알림 발송 (광고·마케팅 목적 알림은 발송하지 않으며, 앱 설정 > 알림에서 언제든지 수신을 거부할 수 있습니다)

제3조 (개인정보의 보유 및 이용 기간)

계정 삭제가 완료되면 계정 개인정보를 지체 없이 파기합니다. 법정 보존 예외와 아래 백업 기준이 적용됩니다. 계정 삭제와 별도로 처리되는 진단·문의 기록은 아래 공개 전 확정 항목입니다.

  • 앱 내 탈퇴는 삭제 완료 여부를 확인합니다. Apple 처리 재시도가 필요할 수 있습니다. 이메일 삭제 요청에는 별도의 본인 확인·처리 시간이 적용됩니다.
  • 단, 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.
  • 서비스 안정성을 위한 암호화 백업본은 생성 후 7일 이내에 자동 삭제됩니다. (2026년 10월 26일 시행)
보존 항목 근거 법령 보존 기간
계약 또는 청약철회 등에 관한 기록 전자상거래 등에서의 소비자보호에 관한 법률 5년
로그인 기록 통신비밀보호법 3개월

Apple 권한 철회용 토큰은 암호화해 계정과 연결하여 저장하며, 탈퇴 처리 시 권한 철회를 시도한 뒤 계정 삭제와 함께 삭제합니다. 직접 철회가 필요한 경우 앱에서 안내할 수 있으며, 일시적인 Apple 오류로 탈퇴가 완료되지 않았다면 재시도 안내를 제공합니다. 이미 공지된 백업본 보관 기준은 그대로 적용됩니다.

공개 전 확정할 사항: Sentry 진단 정보와 이메일 문의 기록의 실제 보관 기간·삭제 경로는 계정 DB 삭제와 별도로 확인해야 합니다. 이를 임의로 ‘즉시 삭제’나 특정 일수로 약속하지 않습니다. 위 기존 법정 보존 표의 실제 적용 범위도 기존 약관 담당의 검토와 합쳐 확정합니다.

제4조 (개인정보의 제3자 제공)

서비스는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만, 다음의 경우에는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령의 규정에 의하거나, 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우

서비스는 원활한 서비스 제공을 위해 다음과 같이 개인정보 처리를 위탁합니다.

Apple(iOS APNs)과 Google(Android FCM)은 해당 플랫폼의 푸시 전달 과정에 관여합니다. Apple·Google·카카오 등 선택한 로그인 제공자의 자체 서비스에는 각 제공자의 정책도 적용됩니다. 위탁 처리와 각 사업자의 독립적인 처리를 동일하게 단정하지 않습니다.

제5조의2 (국외 처리 관련 고지 — 공개 전 검토)

Supabase 데이터베이스의 현재 리전은 대한민국 서울(ap-northeast-2), API 서버는 서울(asia-northeast3), Sentry 조직은 미국 리전으로 확인했습니다. 이 사실만으로 각 업체의 모든 처리가 해당 국가 안에서만 이뤄진다고 단정하지 않습니다. 인증 이메일·푸시·콘텐츠 전송·백업의 실제 이전 국가, 이전받는 자의 연락처, 항목·시기·방법·목적·보유 기간, 이전 근거와 거부 방법/효과를 확정해야 합니다. 이 문단은 최종 법정 고지를 대신하지 않으며, 해당 사항을 완성하기 전 이 개정안을 게시하지 않습니다.

제6조 (이용자의 권리·의무 및 행사 방법)

이용자는 언제든지 다음의 권리를 행사할 수 있습니다.

  1. 개인정보 열람 요구
  2. 오류 등이 있을 경우 정정 요구
  3. 삭제 요구
  4. 처리 정지 요구

위 권리 행사는 지원되는 버전의 앱 내 설정 화면에서 직접 처리하거나, 아래 연락처로 요청하실 수 있습니다.

  • 회원 탈퇴: 앱 설정 → 프로필 → 회원탈퇴
  • 개인정보 수정: 앱 설정 → 프로필 → 정보 수정

제7조 (아동의 개인정보 보호)

서비스는 회원가입을 통해 만 14세 미만 아동의 계정 정보를 직접 수집하지 않습니다. 아동이 사용할 보호자 계정은 부모 또는 법정대리인이 관리합니다. 아이 모드를 지원하는 버전에서는 계정 없이 지정된 동화를 읽을 수 있으며, 계정 기능으로 이동하기 전에 보호자 확인을 거칩니다. 해당 기능을 아직 제공하지 않는 구버전에 같은 제어가 적용된다고 보장하지 않습니다.

아이 모드 지원 버전의 생년월일 입력은 기기에서 연령 구분에 사용하고 원문을 저장·서버 전송하지 않으며, 연령 구분과 전환 상태만 기기에 저장합니다. 이는 정부 신분증이나 법정대리인 신원을 인증하는 절차가 아닙니다. 아이 모드의 네트워크 요청에도 콘텐츠 제공에 필요한 접속 정보 처리는 발생할 수 있습니다.

만 14세 미만 아동의 개인정보가 수집된 사실을 알게 된 경우, 해당 정보를 즉시 삭제하며 법정대리인에게 통지합니다.

제8조 (개인정보의 안전성 확보 조치)

서비스는 개인정보의 안전성 확보를 위해 다음과 같은 조치를 취합니다.

  1. 비밀번호 암호화: 비밀번호는 단방향 암호화하여 저장
  2. 전송 구간 암호화: HTTPS(TLS) 적용
  3. 접근 제한: 개인정보 처리 시스템에 대한 접근 권한 최소화
  4. 인증 토큰: JWT 기반 인증으로 세션 보안 유지. Apple 권한 철회용 토큰은 서버에서 암호화하고 접근을 제한
