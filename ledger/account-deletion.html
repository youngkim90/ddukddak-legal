뚝딱가계부 계정과 계정에 연결된 데이터의 삭제를 요청할 수 있습니다. 계정 삭제는 되돌릴 수 없으며, 같은 이메일로 다시 가입해도 삭제된 계정과 데이터는 복구되지 않습니다.

1. 앱에서 직접 삭제

  1. 뚝딱가계부 앱에서 더보기를 선택합니다.
  2. 프로필을 선택합니다.
  3. 계정 삭제를 선택합니다.
  4. 삭제 범위를 확인하고 현재 비밀번호와 확인 문구를 입력합니다.
  5. 계정 영구 삭제를 선택합니다.

앱에서 요청하면 비밀번호를 다시 확인한 후 계정 삭제를 즉시 처리합니다. Android 기기에 남은 문자·앱 알림 가져오기 대기 데이터도 삭제 절차에서 함께 정리합니다.

2. 앱 없이 이메일로 요청

앱을 설치하지 않았거나 로그인할 수 없는 경우 아래 이메일로 삭제를 요청할 수 있습니다.

3. 삭제되는 데이터

상황 삭제 또는 처리되는 데이터 처리 시점
모든 계정 인증 계정, 이메일, 프로필 이름, 멤버십 앱 내 요청 시 즉시
다른 그룹원이 있는 공유 장부 탈퇴자가 만든 반복 거래 규칙과 결제 가져오기 지문·승인번호·카드 끝자리 등 구조화 메타데이터 계정 삭제 시
마지막 1인인 장부 장부, 거래, 반복 규칙, 카테고리, 자산, 예산, 구성원, 결제 가져오기 메타데이터 계정 삭제 시
Android 기기 뚝딱가계부가 기기에 보관한 문자·금융 앱 알림 원문 대기 데이터 인앱 삭제, 수집 끄기, 로그아웃 또는 앱 데이터 삭제 시. 이메일로 삭제한 경우에도 최대 24시간 뒤 만료됩니다.

4. 공유 장부에 남는 데이터

다른 그룹원이 남아 있는 경우 공동 장부의 연속성을 위해 이미 공유된 거래 기록은 남은 그룹원의 공동 기록으로 유지됩니다. 이때 탈퇴자의 사용자 ID, 작성자 연결, 구성원 귀속은 제거되어 탈퇴 계정과 연결되지 않도록 처리합니다.

탈퇴자가 그룹장이면 관리자 우선, 이후 먼저 가입한 그룹원 순으로 새 그룹장을 지정합니다.

참여 코드 사용·변경 같은 그룹 보안 이력은 다른 그룹원의 계정 보호를 위해 탈퇴자 식별자를 제거한 형태로 그룹이 유지되는 동안 남을 수 있습니다.
